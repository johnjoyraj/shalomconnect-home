Privacy Policy

Effective Date: 2026

Shalom Connect (https://shalomconnect.in) serves as a central navigation directory connecting independently operated web applications.

1. Central Homepage Data Collection

The master homepage at shalomconnect.in is a static informational directory. It does not require user registration, does not process payments directly, and does not store personal user databases on this root site.

2. Independent Subdomain Applications

Each linked service (including connecthub.shalomconnect.in, family.shalomconnect.in, store.shalomconnect.in, pray.shalomconnect.in, school.shalomconnect.in, whatsapp.shalomconnect.in, and billbook.shalomconnect.in) operates independently with its own authentication, database, and privacy controls. When you visit a subdomain application, that application's own terms and privacy practices apply.

3. Technical Logs & Hosting

Standard web hosting and CDN infrastructure (such as GitHub Pages) may process basic request metadata (such as IP address and browser user agent) to deliver pages securely over HTTPS.

4. Contact

For privacy questions regarding the central portal, please refer to the Contact section.
